# Local Docker demo: release v7

From the repository root run `bash scripts/demo.sh`, then open
http://127.0.0.1:8080. Use `bash scripts/demo.sh status`, `logs`, or `stop`.
Docker Desktop or Docker/Colima and Compose must be installed. The first build
downloads dependencies. The script supports a dedicated `phishx` Colima VM on this
Mac. Only localhost port 8080 is published; API port 8000 stays internal.

Obtain the trusted private `PhishX_release_v7_local_demo.zip` handoff separately,
and extract it at the repository root. Its files go under `artifacts/release-v7/`.
Compare SHA-256 checksums against `docs/evidence/completion/release-v7-artifacts.json`.
Never load untrusted joblib/pickle artifacts. Weights, rank snapshots and raw
training data are excluded from Git and Docker images; the directory mounts
read-only. The full v7 handoff is required; the older RF-only ZIP is insufficient.
The local private ZIP is generated by `PYTHONPATH=ml:. .venv/bin/python scripts/package_release.py`.

The default provider loads the frozen RF, character CNN, learned fusion and frozen
Tranco context. Its factory recomputes the registered quality gates from measured
counts and checks frozen model/code hashes. It refuses failed candidates. Current
model version: `cascade-release-v7-a89fff3e7d31`. See
[measured evaluation and limitations](../docs/project-completion.md).

Live checks run only after the explicit button click and never change the model
score. Disable them with `PHISHX_LIVE_SIGNALS=0 bash scripts/demo.sh`.
The API runs as nonroot with a read-only root filesystem and temporary `/tmp`.
Nginx provides same-origin proxying, security headers, size and rate limits.
This is a local academic demo, with no public deployment or production claim.

To release VM memory, stop the containers, then run `colima stop phishx`.
For a plain local developer session, run `.venv/bin/python scripts/start_dev.py --live`;
this also selects v7 and reports occupied ports without killing other processes.
